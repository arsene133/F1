Ce thème intègre l'extension [@astrojs/mdx](https://docs.astro.build/fr/guides/integrations-guide/mdx/) installée et configurée dans votre fichier `astro.config.mjs`.

## Pourquoi MDX ?

MDX est une variante de Markdown qui prend en charge la syntaxe JavaScript et JSX. Cela permet d’[intégrer du JavaScript et des composants d'interface utilisateur directement dans vos contenus Markdown](https://docs.astro.build/fr/guides/integrations-guide/mdx/#mdx-in-astro) pour concevoir des graphiques interactifs ou des alertes.

## Exemple

Voici comment importer et utiliser un composant d'interface dans MDX.

import HeaderLink from '../../components/HeaderLink.astro';

<HeaderLink href="#" onclick="alert('Cliqué !')">
	Composant interactif intégré dans MDX
</HeaderLink>
